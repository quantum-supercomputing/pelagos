# Security policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, pull
requests, or discussions.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/quantum-supercomputing/pelagos/security/advisories/new).
Only the maintainers can see these reports.

Please include a description of the issue, the steps to reproduce it, the affected versions,
and its potential impact. We will acknowledge your report within 5 business days and keep you
informed as we work on a fix. Please give us a reasonable amount of time to release a fix
before any public disclosure.

## Supported versions

Pelagos is in early development (0.x). Security fixes are made on the latest release only.
