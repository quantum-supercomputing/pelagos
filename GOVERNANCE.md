# Governance

Pelagos uses a lightweight, maintainer-led governance model. The current maintainers are
listed in [MAINTAINERS.md](MAINTAINERS.md).

## Maintainers

Maintainers are trusted contributors responsible for project direction, releases, and
contribution review.

An *active maintainer* is anyone listed under "Active maintainers" in
[MAINTAINERS.md](MAINTAINERS.md). A maintainer may step down at any time by opening a pull
request that moves their name to "Emeritus maintainers." Emeritus maintainers do not vote,
and they may return by the same process as a new maintainer.

## Decision-making

Routine decisions, such as reviewing and merging pull requests or triaging issues, are
delegated to the relevant maintainers.

Significant decisions are discussed publicly in a GitHub issue or pull request and decided
by maintainer consensus. Significant decisions include changes to the public API, the
release process, the license, or the project's scope. If consensus cannot be reached, a
majority of active maintainers decides.

## Membership

New maintainers are nominated on the basis of sustained contributions to the project. A
nomination is made by opening a pull request that adds the nominee to
[MAINTAINERS.md](MAINTAINERS.md). The nomination is approved by a majority of active
maintainers.

## Disagreements

Disputes should first be resolved through good-faith discussion. If a dispute remains
unresolved, maintainers who are not involved in it make the final decision.

## Changes to governance

Changes to this document require public notice, given as a pull request that stays open for
at least 14 days, and approval by a two-thirds supermajority of active maintainers.
